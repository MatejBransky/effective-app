# Tasks directory

- When working on the life-coaching example, read
  `tasks/life-coaching-example.md` (requirements + plan) and
  `tasks/life-coaching-glossary.md` (canonical terms) first.
- Use the glossary's exact terms and identifiers in code, Effect Schema, API
  contracts, and docs. Do not introduce its banned synonyms. If a new domain
  term is needed, add it to the glossary in the same change.
- Write all docs and code in English. Keep both documents terse and
  business-focused.
